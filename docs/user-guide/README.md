# RivetMSP user guide

Guides for the RivetMSP web app. Every screenshot uses fictional demo data (Northwind Managed IT); your screens show your own company, clients and colours. Screenshots live in [images/web-app](images/web-app/README.md).

| Guide | Read it if you... |
|---|---|
| [1. Getting started](01-getting-started.md) | are new: sign in, find your way around, search, set up your account |
| [2. Service desk](02-service-desk.md) | work tickets: lists, views, replies, time, bulk actions |
| [3. Clients, contacts and assets](03-clients-contacts-assets.md) | look after clients: overview, contacts, assets, documentation |
| [4. Sales and CRM](04-sales-and-crm.md) | handle leads and opportunities |
| [5. Quotes, invoices and payments](05-quotes-invoices-payments.md) | do the billing |
| [6. Projects and calendar](06-projects-and-calendar.md) | plan work |
| [7. Dashboard and reports](07-dashboard-and-reports.md) | answer "how are we doing" questions and export numbers |
| [8. Client portal](08-client-portal.md) | support clients who sign in to raise tickets and see invoices |
| [9. Administration](09-administration.md) | run the system: users, roles, settings, ticketing setup, compliance, health |

What you see depends on your **role** (Administrator, Accountant or Technician out of the box) and on which modules an administrator switched on, so some entries below may be missing on your screen.
